# Code of Conduct

datasniff follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep feedback about the work and not the person, and help newcomers.

## Reporting

If someone's behaviour in an issue, pull request or discussion makes you uncomfortable, contact the maintainer privately through the email on [@kaajjalchoudhary](https://github.com/kaajjalchoudhary)'s GitHub profile. Reports are kept confidential.

Maintainers may edit, hide or remove comments, commits and issues that break these rules, and may block repeat offenders.
